# Demo video: script and recording guide

Target length: **about 5 minutes.** Three files, three stories, each ending at **posture 100 with 0 problems**:

| Scene | File (`demo-sih/`) | Story |
|---|---|---|
| 2 | `cisco_oneclick.cfg` | A dedicated parser: a very bad score, every problem fixed in one click |
| 3 | `paloalto_ai_human.cfg` | No parser: some problems fixed by NetAuditAI, the rest by the AI or a person, every fix checked |
| 4 | `unknown_vendor.cfg` | A vendor nobody has seen: teach it first, then fix it |

Every flow was run end to end, and `backend/tests/test_demo_fix_to_100.py` keeps them working. The exact commands are
in [demo-sih/README.md](../demo-sih/README.md).

---

## Before you record (off camera)

1. **Start the backend and frontend.**
   ```powershell
   cd backend; .\venv\Scripts\activate
   python -m uvicorn app.main:app --host 0.0.0.0 --port 8001
   ```
   ```powershell
   cd frontend; npm run dev
   ```
   Leave out `--reload`, so the server doesn't restart halfway through a take.
2. **Make sure the unknown vendor is untaught.** Taught knowledge is saved permanently: in your Postgres database when
   `DATABASE_URL` is set in `backend/.env`, otherwise in `backend/data/adaptive.db`. Open **Adaptive learning →
   Learned mappings** and, if any of these three are listed under *Taught here*, stop them:
   `remote-console protocol …`, `secure-shell protocol-version …`, `operator inactivity-lock …`.
   Do this again before every retake of scene 4.
3. **Warm up.** Run one throwaway scan: the first scan after a start takes about a minute, later ones a few seconds.
4. **Check AI.** Scene 3 uses *Ask AI for a command*. If AI isn't configured or its quota is used up, type the
   command instead (the story still holds: a person proposes, NetAuditAI checks).
5. **Screen:** browser zoom 110–125%, other tabs closed, notifications off, the `demo-sih/` folder ready in the file
   picker, and `docs/presentation.pptx` open for the first and last slides.

## Script

### Scene 1: The problem (0:00–0:20). Show: slide 1

> "Every network vendor writes security settings differently. Checking them by hand is slow, and a tool that guesses
> is worse than no tool. NetAuditAI audits any vendor's configuration against NIST, DISA STIG, ISO 27001 and CIS,
> proves every verdict with the line that decides it, and fixes what it can prove is safe."

### Scene 2: Cisco, fixed in one click (0:20–1:30)

**Do:** **New scan** → add `cisco_oneclick.cfg` → **Start scan**.

**Show:** Overview: posture **41**, **15 problems**, read by the Cisco parser.

> "A Cisco edge router. The score is 41 out of 100, with 15 problems: Telnet, SSH version 1, weak VPN encryption,
> no AAA, no idle timeout."

**Do:** **Findings** → open **MGMT-001 Telnet**.

> "Every finding cites the exact line that caused it and the NIST and CIS requirements it breaks."

**Do:** **Remediation**. Point at *can be fixed automatically*.

> "Every one of these fixes is generated by NetAuditAI itself, with no AI and no input from me. Each one is applied to
> a copy of the file and the copy is rescanned before it counts."

**Do:** **Download corrected configuration** → **New scan** → upload the downloaded file → **Start scan**.

**Show:** posture **100**, **0 problems**.

> "One click, and the rescan of the corrected file is 100 with zero problems. NetAuditAI never touches the device:
> the engineer reviews this file and applies it."

### Scene 3: Palo Alto, AI and a person, every fix checked (1:30–3:00)

**Do:** **New scan** → `paloalto_ai_human.cfg` → **Start scan**.

**Show:** posture **30**, **10 problems**, vendor *not confirmed* (no dedicated parser).

> "A Palo Alto firewall. We have no Palo Alto parser. It's read by shipped knowledge instead, and it still finds 10
> problems, each with its line."

**Do:** **Remediation**. Point at the five fixed by NetAuditAI (Telnet, HTTP, SSH v1, idle timeout, LLDP).

> "Five of them NetAuditAI fixes itself, because it knows how this syntax writes the secure setting."

**Do:** on **Missing Login Banner** press **Ask AI for a command** → **Verify candidate** → **Confirm**.

> "For the rest, I can ask the AI. Its answer is only a candidate: NetAuditAI applies it to a copy, rescans it, and
> only a verified command can be confirmed. If the AI gets it wrong, it's rejected, and I can ask again."

**Do:** on **No Remote Syslog Server Configured** press **Enter command manually**, type
`set deviceconfig system syslog-server 10.60.99.50` → **Use this command** → **Verify candidate** → **Confirm**.

> "Or a person types it. Same check, same rule: nothing counts until it is verified and confirmed."

*(Off camera, or sped up: the other three from the README. AAA, NTP authentication, password length.)*

**Do:** **Download corrected configuration** → new scan of the downloaded file.

**Show:** posture **100**, **0 problems**.

> "Fixed by NetAuditAI, by the AI and by a person, and every fix was proven before it counted. 100, zero problems."

### Scene 4: A vendor nobody has seen, taught then fixed (3:00–4:30)

**Do:** **New scan** → `unknown_vendor.cfg` → **Start scan**.

**Show:** *Unfamiliar device*, no score, three *suspected* problems.

> "Now a device from a vendor NetAuditAI has never seen. It spots three things that look like problems, but it won't
> score a guess. That's why there's no score yet."

**Do:** **Adaptive learning**. Confirm what line 16 means (Telnet), then line 18 (SSH version), then line 20
(idle timeout).

> "I teach it once: this line means Telnet is on. This one is the SSH version. This one is the idle timeout. No AI was
> needed, and from now on every scan of this vendor reads these lines itself."

**Show:** the three problems are now confirmed and scored: posture **0**.

**Do:** **Remediation** → on each problem **Enter command manually**, **Verify candidate**, **Confirm**:
`remote-console protocol ssh`, `secure-shell protocol-version 2`, `operator inactivity-lock 10 minutes`.

> "Because it has learned these lines, it can check my fixes too."

**Do:** **Download corrected configuration** → new scan of the downloaded file.

**Show:** posture **100**, **0 problems**.

> "From never seen, to taught, to fixed and proven. 100, zero problems."

### Scene 5: Trust, and the numbers (4:30–5:00). Show: Audit ledger, then slide 3

**Do:** **Audit ledger** → **Verify the ledger**. Should read *Intact*.

> "Every scan, every lesson and every fix decision is recorded in a tamper-evident ledger. On nine real
> configurations it had never seen, NetAuditAI caught 21 of 21 insecure settings with zero false alarms. AI only
> proposes; NetAuditAI proves; a person decides. That's NetAuditAI."

## Tips

- **Record each scene as its own clip,** so a mistake only costs one clip. Join them in Clipchamp (built into Windows)
  or any editor. Record with Win + Alt + R, or OBS.
- **Cut the waiting:** scan spinners, file pickers, and the extra Palo Alto commands.
- **If the AI's answer is rejected on camera,** keep it in. Say "it rejected the AI's command because it didn't hold
  up", then type the README command.
- **Short on time?** Shorten scene 3 to one AI fix and one typed fix. Keep scenes 2 and 4 whole.
- **Say only what the app does.** It never pushes a change to a device. Its dedicated parsers are Cisco IOS and
  FortiGate; everything else is read by shipped or taught knowledge.
